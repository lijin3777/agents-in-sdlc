前の 2 つの演習では、ユーザー体験の改善と機能追加を目的とする 3 つのタスクを Copilot クラウドエージェントに依頼しました。クラウドエージェントは自律的に非同期で動作しますが、作業を監視することも重要です。

GitHub.com の[エージェントページ][agents-page]など、クラウドエージェントに割り当てたタスクを管理する方法はいくつかあります。このミッションコントロールでは、オープンなプルリクエスト (PR) があるエージェントのタスクを一覧で確認できます。実行された操作を調べたり、進行中のセッションを誘導して作業の方向を調整したりすることもできます。

このレッスンでは、次のことを行います。

- エージェントページを使って、クラウドエージェントのタスクを監視します。
- 進行中のセッションを誘導し、機能を追加で依頼します。

## シナリオ

ハイコントラストモードの作成をエージェントに依頼した後、チームはライトモードも追加するよい機会だと考えました。サイトのスタイル更新と切り替え機能の実装はすでに進んでいるため、同時に追加するのが適切だと判断しました。ハイコントラストに加えてライトモードも実装するよう、エージェントの作業を誘導します。

## Copilot クラウドエージェントのタスクを確認する

Copilot クラウドエージェントに割り当てたすべてのタスクの現在の状態を確認しましょう。

1. [Copilot agents ページ](https://github.com/copilot/agents)に移動します。
2. メインペインと左ペインの両方に表示されるタスクの一覧を確認します。Copilot に割り当てた次のタスクが表示されます。
    - コードベースのドキュメントを更新する。
    - ゲームを変更する API を生成する。
    - Web サイトにハイコントラストモードを追加する。
3. 実行中のタスクを選択し、Copilot が実行した操作を確認します。たとえば、次のような操作があります。
    - リポジトリからコードをチェックアウトする。
    - Copilot の作業環境を作成する。
    - MCP サーバーをセットアップする。
    - 割り当てられたタスクを完了するための各種手順を実行する。

> [!NOTE]
> 表示される手順は、Copilot の作業状況と実施方法によって異なります。

4. 右側に表示されるプルリクエスト (PR) ペインも確認します。ここでは、追加の監視に使える PR と変更ファイルを確認できます。

## クラウドエージェントを誘導する

進行中のタスクを確認したので、ハイコントラストモードの作業中にライトモードの切り替えも追加するよう Copilot に依頼しましょう。

1. ハイコントラストモードを追加するセッションを選択します。正確なタイトルは Copilot が付けた名前と作業状態によって異なります。

    ![ミッションコントロールのアクセシビリティセッション](../../../_images/ex6-accessibility-session.png)

2. セットアップが完了し、作業が始まったことを示すメッセージが表示されるまで、数分間セッションを確認します。
3. **Steer active session while Copilot is working** ダイアログで、次のプロンプトを追加します。

    ```plaintext
    While we are working on a high contrast mode, let's also add a light mode. There should be a switch for this mode as well where users can select their desired display mode.
    ```

    ![エージェントページのクラウドエージェントタスクで、Copilot の作業中にアクティブなセッションを誘導するダイアログが強調表示されたスクリーンショット](../../../_images/ex6-steer-cloud-agent-task.png)

4. <kbd>Enter</kbd> を押してプロンプトを送信します。
5. Copilot がプロンプトを受け取り、作業に加えたことを確認します。

## Copilot に作業を任せる

Copilot は更新されたタスクに取りかかります。メッセージを送信した時点で実行中だった手順が終わると、新しい依頼を作業に反映します。

これまでと同様に、作業には数分かかります。その間に一息ついて、ここまでに学んだことや確認したことを振り返りましょう。

## まとめと次のステップ

このレッスンでは、GitHub Copilot クラウドエージェントの監視と誘導に使う中心的な場所である、Copilot agents ページについて学びました。このミッションコントロールで、進行中または完了済みのタスクを追跡し、実行中の作業を確認し、範囲の調整や追加の指示のために進行中のタスクの方向を変えることができます。

次の概念を確認しました。

- ミッションコントロールとエージェントページを使って、クラウドエージェントのタスクを監視しました。
- 進行中のセッションを誘導し、追加機能を依頼しました。

Copilot がアクセシビリティ機能を完成させている間に、Copilot が作成したプルリクエストを[反復的に改善する][next-lesson]方法を確認しましょう。
