**[GitHub Copilot CLI][about-copilot-cli]** を使うと、GitHub Copilot をエージェント型コーディングアシスタントとしてターミナルから利用できます。コマンドラインからコードベースを調査し、コードを生成してコマンドを実行し、外部ツールに接続できます。グラフィカルエディターに切り替えずに作業を続けられます。

このワークショップでは、Tailspin Toys で一連のワークフローに取り組みます。

1. GitHub Codespaces でプロジェクトを準備し、Copilot CLI をインストールして、使い方を確認します。
2. 星評価に対象を絞った変更を加え、ブラウザーでレビューして、最初のプルリクエスト (PR) を手動でマージします。
3. フィルター機能の issue から始め、Plan モードでアプローチを定義し、Autopilot モードで実装して、Interactive モードでレビューします。
4. リポジトリの指示を更新し、フィルター機能の作業に適用します。
5. 既存の `quality-checks` スキルをカスタマイズし、プロジェクトのチェックを実行します。
6. Playwright Model Context Protocol (MCP) サーバーを追加し、ブラウザーでフィルター機能を試します。
7. 品質保証 (QA) カスタムエージェントを作成して、要件、カバレッジ、検証の根拠をレビューします。
8. フィルター機能の変更全体をレビューし、フィルター機能の PR に Agent Merge を使います。
9. コンテキスト、モデル、共有、任意のクラウドへの委任に使えるスラッシュコマンドを確認します。

ワークショップの焦点を絞るため、PR は 2 つ作成します。1 つ目は星評価、2 つ目はフィルター機能と指示・スキル・QA プロファイル・テストの更新です。フィルター機能と品質ワークフローでは、1 つの会話とブランチを共有し、ツールを学びながら作業を積み重ねます。

## 前提条件

このワークショップに参加する前に、次のものを用意してください。

- [ ] 有効な **Copilot Student、Pro、Pro+、Business、Enterprise** プランを持つ GitHub アカウント
- [ ] リポジトリと Codespace を作成する権限
- [ ] ターミナルまたはコマンドラインの基本的な知識

> [!TIP]
> 有料プランを利用していない場合、認定を受けた学生は [GitHub Education][student-plan] を通じて GitHub Copilot を無料で利用できます。**Copilot Student** プランには、このワークショップで使うエージェント、MCP、コードレビュー、Copilot CLI の機能が含まれています。

> [!NOTE]
> Copilot Business または Copilot Enterprise を使用している場合、管理者が Copilot CLI を有効にしていることを確認してください。
