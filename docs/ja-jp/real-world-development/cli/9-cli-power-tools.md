多くの CLI ツールと同様に、GitHub Copilot CLI には対話に使えるスラッシュコマンドが多数あります。これらのコマンドでは、高度な機能、内部情報、追加の構成オプションを利用できます。これまでに `/diff`、`/mcp`、`/skills`、`/agent`、`/pr` などのコマンドを使いました。ここでは、ほかの便利なコマンドも確認しましょう。

このレッスンでは、次のことを行います。

- `/context` と `/compact` で、Copilot が会話のコンテキストを管理する方法を確認します。
- `/model` で、利用可能なモデルを確認します。
- `/share` でセッションをエクスポートまたは共有する方法を学びます。
- 並行作業、worktree、クラウドエージェントへの委任に使える任意のコマンドを確認します。

## シナリオ

CLI の主要なワークフローが完了したので、コンテキスト管理、モデルの切り替え、セッションの共有、任意の [Copilot クラウドエージェント][about-cloud-agent]への委任など、追加機能を確認しましょう。

## Copilot CLI のコンテキストを確認する

大規模または複雑なタスクでは、モデルの最大コンテキストウィンドウに達することがあります。Copilot CLI は必要に応じて会話を自動的に圧縮します。また、スラッシュコマンドを使って自分で状態を確認したり圧縮したりできます。

1. Codespace に戻ります。Copilot CLI がまだ開いていない場合は、リポジトリのルートから起動します。
2. 次を入力します。

   ```plaintext
   /context
   ```

3. モデル、現在のトークン使用量、システム指示、ツール、メッセージ、空き領域にコンテキストがどのように分けられているかを確認します。
4. 会話を圧縮します。

   ```plaintext
   /compact
   ```

5. もう一度 `/context` を実行し、結果を比較します。会話が小さい場合、大きな違いはないことがあります。

> [!NOTE]
> Copilot CLI は、コンテキストウィンドウが埋まると自動的にコンテキストを圧縮します。自分でタイミングを選びたい場合は `/compact` を使います。無関係なタスクに移るときに新しい会話を始めたい場合は、`/clear` または `/new` を使います。

## モデルを選ぶ

モデルごとに強みが異なり、開発者によって好みも異なります。Copilot CLI では、利用可能なモデルを一覧表示し、使用するモデルを選択できます。

1. 次を入力します。

   ```plaintext
   /model
   ```

2. 利用可能なモデルと使用状況に関する情報を確認します。
3. 現在のモデルを使い続けるか、別のモデルを選択するか、<kbd>Esc</kbd> を押して一覧を閉じます。

## セッションを共有する

チームで協力して学びを共有すると、AI ツールをより効果的に使えるようになります。`/share` コマンドを使うと、セッションを Markdown または HTML ファイルにエクスポートしたり、共有リンクを作成したり、GitHub gist を公開したりできます。

1. `/help` を入力し、インストール済みのバージョンで利用できる `/share` のオプションを確認します。
2. セッションを共有する場合は、ローカルの Markdown にエクスポートする `/share file` など、目的に合った出力先を選びます。
3. エクスポートした内容を誰かに送ったり公開したりする前に確認します。セッションのエクスポートには、プロンプト、応答、プロジェクトの詳細が含まれることがあります。

リンクや gist の公開は任意です。チームが共有を予定していないリポジトリや会話の内容は公開しないでください。

## 任意: 作業を拡張または委任する

コアとなるワークショップは完了です。Copilot CLI には、大きなタスクに役立つコマンドもあります。

- `/fleet` は、独立したサブタスクをサブエージェントに割り振り、並行して実行できます。
- `/worktree` は、別のタスク用に分離された Git worktree を作成できます。
- `/delegate` は、非同期に作業し、プルリクエストを作成する場合もある Copilot クラウドエージェントにタスクを送信できます。

これらのコマンドを使うと、追加の worktree が作成されたり、リモート作業が始まったりすることがあるため、任意の項目として紹介しています。試すときは、タスクの範囲を明確にしてから、新しい会話で開始し、通常のワークフローで結果をレビューしてください。非同期エージェントの作業を詳しく確認するには、[クラウドエージェントのワークショップ][cloud-workshop]に進んでください。
